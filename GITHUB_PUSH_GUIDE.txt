================================================================================
ARC-NOMADE — STEP-BY-STEP GITHUB PUSH GUIDE 🧭✈️
================================================================================

This guide explains how to initialize and push your ARC-NOMADE project to a brand
new GitHub repository safely and cleanly.

--------------------------------------------------------------------------------
PREREQUISITES & PRE-CHECK
--------------------------------------------------------------------------------
1. Make sure you have Git installed:
   Open terminal and type:
   git --version

2. A GitHub account:
   https://github.com

3. Secret Protection (ALREADY CONFIGURED):
   A root `.gitignore` file has been configured for you so that:
   - Your private API keys in `backend/.env` are NEVER uploaded to GitHub.
   - Large virtual environments (`venv/`) and Node modules (`node_modules/`, `.next/`)
     are excluded automatically.
   - Local database files (`arc_nomade.db`) remain local.

================================================================================
STEP 1: CREATE A NEW REPOSITORY ON GITHUB
================================================================================
1. Open your browser and go to: https://github.com/new
2. Repository name: Arc-Nomad  (or any name you prefer)
3. Description: AI-Powered Collaborative Travel Planning & Group Expedition Management Platform
4. Set to: Public or Private (your choice)
5. IMPORTANT: Do NOT check "Add a README file", "Add .gitignore", or "Choose a license"
   (we already have all of these files created locally).
6. Click the green "Create repository" button.
7. Copy your repository URL, which looks like:
   HTTPS: https://github.com/<YOUR_GITHUB_USERNAME>/Arc-Nomad.git
   or
   SSH:   git@github.com:<YOUR_GITHUB_USERNAME>/Arc-Nomad.git

================================================================================
STEP 2: RUN GIT COMMANDS IN TERMINAL
================================================================================
Open PowerShell or Command Prompt in the root folder of this project:
Path: d:\projects and certificates\projects\web\Arc-Nomad

Run each of the following commands in order:

1. Initialize Git repository:
   git init

2. Verify that .env and node_modules are properly ignored:
   git status
   (Notice that `backend/.env`, `venv/`, and `node_modules/` should NOT appear!)

3. Stage all project files:
   git add .

4. Commit the project:
   git commit -m "feat: Initial release of ARC-NOMADE travel planning platform"

5. Rename your default branch to main:
   git branch -M main

6. Link your local project to your GitHub repository:
   Replace <YOUR_GITHUB_URL> with the URL you copied in Step 1:
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/Arc-Nomad.git

   Example:
   git remote add origin https://github.com/rohan/Arc-Nomad.git

7. Push your code to GitHub:
   git push -u origin main

================================================================================
ALTERNATIVE: 1-CLICK PUSH USING GITHUB CLI (gh)
================================================================================
If you have the GitHub CLI installed (`gh`), you can do everything in 3 commands:

   git init
   git add .
   git commit -m "feat: Initial release of ARC-NOMADE travel platform"
   gh repo create Arc-Nomad --public --source=. --remote=origin --push

================================================================================
HOW TO PUSH FUTURE UPDATES
================================================================================
Whenever you make future changes to the project, run:

1. Stage modified files:
   git add .

2. Commit changes with a descriptive message:
   git commit -m "feat: added new travel features and improvements"

3. Push changes to GitHub:
   git push

================================================================================
HELPFUL TROUBLESHOOTING
================================================================================
Q1: "remote origin already exists" error?
Run:
   git remote remove origin
Then re-run:
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/Arc-Nomad.git

Q2: Authentication failed during push?
GitHub requires a Personal Access Token (PAT) instead of your account password:
1. Go to GitHub Settings -> Developer Settings -> Personal Access Tokens -> Tokens (classic)
2. Generate a new token with "repo" scope checked.
3. Copy the token and paste it as your password when Git prompts you.
Or authenticate seamlessly via GitHub CLI:
   gh auth login

Q3: Large file warning or accidental .env commit?
Check `.gitignore` to ensure `.env` and `venv` are listed before running `git add .`.
If you ever staged `.env` by mistake before committing, unstage it with:
   git reset backend/.env
